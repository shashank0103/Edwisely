SCENARIO BASED ANSWERS (SHORT FORM)
=========================================================
1) Web + DB Design:
Web server → Public subnet
Database → Private subnet
2) Public EC2 no internet:
Check IGW + route table + public IP
3) App to RDS:
Allow SG-to-SG communication on DB port (3306)
4) CIDR for future scaling:
Choose larger CIDR like /16
5) On-prem connectivity:
VPN (cost-effective)
Direct Connect (high bandwidth, dedicated)
6) Same CIDR VPC peering issue:
Use Transit Gateway + CIDR redesign
7) Microservices communication:
Use security groups, not public IP
8) 3-tier design:
Public (Web)
Private (App)
Private (DB)
9) Monitor traffic:
Use VPC Flow Logs
10) Private subnet no IGW:
Because it should not be internet-facing
